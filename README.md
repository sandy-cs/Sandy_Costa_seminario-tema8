## Resumo

Este trabalho apresenta os conceitos de conteinerização e orquestração, abordando como as tecnologias Docker e Kubernetes ajudam a simplificar o desenvolvimento, a implantação e o gerenciamento de aplicações. Também apresenta um exemplo de utilização no Nubank e uma demonstração prática para ilustrar o funcionamento dessas tecnologias e seus benefícios no ambiente empresarial.
